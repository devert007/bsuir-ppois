# Документация игры Moorhuhn

Этот документ предоставляет исчерпывающее описание реализации игры **Moorhuhn**, представляющей собой тир, разработанный на основе библиотеки Pygame. Игроки используют мышь для стрельбы по анимированным целям (курицам), чтобы набрать очки. Документация охватывает структуру проекта, конфигурацию, реализацию классов, ключевые особенности и инструкции по использованию.

---

## Обзор проекта

**Moorhuhn** — это классическая игра-стрельба, в которой игроки используют мышь для стрельбы по анимированным GIF-целям (курицам), движущимся по экрану. Игра включает меню, систему рекордов, параллакс-фон, звуковые эффекты и фоновую музыку. Основные особенности:

- **Разная музыка**: Отдельная фоновая музыка для меню и игрового процесса.
- **Централизованная конфигурация**: Настройки игры, уровни и характеристики сущностей хранятся в JSON-файле.
- **Модульный дизайн**: Классы разделены по отдельным файлам для лучшей организации.
- **Обработка ошибок**: Надёжная обработка загрузки файлов и переходов между состояниями.
- **Параллакс-фон**: Многослойный фон с разной скоростью прокрутки для эффекта глубины.
- **Пользовательский курсор**: Пользовательский курсор заменяет стандартный указатель мыши для прицеливания.
- **Рекорды**: Постоянное хранение рекордов в JSON-файле.

### Основные директории и файлы

- `main.py`: Инициализирует Pygame, настраивает окно игры и управляет основным игровым циклом, переключая состояния между меню, игрой, рекордами и справкой.
- `config.json`: Хранит все настройки игры, включая размеры экрана, FPS, конфигурацию уровней и свойства сущностей (например, оружие, GIF-объекты, звуки).
- `src/models/`: Содержит основную игровую логику, разделённую на:
  - `game/` для классов, специфичных для игры (`Gun`, `Game`, `TableRecords`, `GifObject`).
  - `menu.py` для системы меню.
- `src/utils/`: Содержит `config_loader.py` для управления конфигурацией.
- `img/`: Хранит графические ресурсы (фоны, иконки, GIF).
- `sound/`: Хранит звуковые эффекты и музыкальные файлы.
- `high_scores.json`: Сохраняет рекорды между игровыми сессиями.

## Конфигурация

Файл `config.json` централизует все настройки игры, упрощая изменение параметров без редактирования кода. Ниже описана его структура.

## Разделы

game_settings:
Определяет глобальные параметры игры, такие как размер экрана, FPS и шрифты.
Используется классами Game, Menu и TableRecords.


levels:
Конфигурирует настройки уровней (в данный момент только уровень 1).
Включает таймеры, интервалы появления целей, скорости и задержки перезарядки.


entities:
Определяет свойства игровых сущностей:
gun: Иконка пули, масштаб и начальное количество боеприпасов.
gif_object: Пути к GIF, диапазоны размеров и поведение особых целей.
background: Слои фона, коэффициенты параллакса и размеры.
cursor: Изображение пользовательского курсора и масштаб.
sounds: Пути к звуковым эффектам и громкость.






## Реализация классов
Игра построена с использованием модульной структуры классов, где каждый класс находится в отдельном файле в директории src/models/. Ниже приведено подробное описание каждого класса.
1. ConfigLoader (src/utils/config_loader.py)
Назначение: Загружает и предоставляет доступ к файлу config.json.
Основные методы:

__init__(self, config_path): Инициализирует загрузчик и загружает JSON-файл.
load_config(self, config_path): Читает JSON-файл, возвращая пустой словарь при ошибке.
get_config(self): Возвращает загруженную конфигурацию.

Использование:

Создаётся в main.py и передаётся другим классам.
Обеспечивает централизованный доступ к конфигурации.

Особенности:

Обработка ошибок для отсутствующих или некорректных JSON-файлов.
Простой интерфейс для доступа к данным конфигурации.

2. TableRecords (src/models/game/table_records.py)
Назначение: Управляет хранением, извлечением и отображением рекордов.
Основные методы:

__init__(self, config): Инициализирует путь к файлу рекордов, загружает рекорды и задаёт шрифт.
load_scores(self): Загружает рекорды из high_scores.json, возвращая пустой словарь при ошибке.
save_score(self, player_name, score): Сохраняет новый рекорд в JSON-файл.
get_top_scores(self, limit=5): Возвращает limit лучших рекордов, отсортированных по убыванию.
draw(self, screen): Отображает таблицу рекордов на экране.

Использование:

Используется в Game для сохранения и отображения рекордов после окончания игры.
Доступ через опцию "records" в меню.

Особенности:

Постоянное хранение с использованием JSON.
Отображение 5 лучших рекордов с именами игроков.
Обработка ошибок для операций с JSON-файлом.
Настраиваемый шрифт и размер через config.json.

3. Gun (src/models/game/gun.py)
Назначение: Управляет боеприпасами игрока (пулями) и их визуальным представлением.
Основные методы:

__init__(self, screen, config): Инициализирует оружие с начальным количеством боеприпасов и загружает изображение пули.
load_pistol_image(self): Загружает иконку пули, возвращая красный прямоугольник при ошибке.
refresh_pistols(self, perezaryad_sound): Перезаряжает боеприпасы и воспроизводит звук перезарядки.
remove_patron(self): Уменьшает количество боеприпасов.
draw_patrons(self): Отображает оставшиеся пули на экране.

Использование:

Создаётся в Game для отслеживания и отображения боеприпасов.
Обновляется при выстрелах или перезарядке.

Особенности:

Настраиваемое изображение пули и масштаб через config.json.
Визуальная обратная связь по количеству боеприпасов.
Звуковой эффект перезарядки.
Обработка ошибок при загрузке изображения.

4. GifObject (src/models/game/gif_object.py)
Назначение: Управляет анимированными GIF-целями (курицами), движущимися по экрану.
Основные методы:

__init__(self, gif_path, x, y, size, speed, bg_width, config, layer="foreground"): Инициализирует GIF-объект с позицией, размером, скоростью и слоем.
load_gif_frames(self, path): Загружает отдельные кадры из GIF с использованием Pillow.
replace_gif(self, new_gif_path): Заменяет текущий GIF на новый (например, для особых куриц).
update(self, dt): Обновляет кадр анимации и позицию на основе времени.
draw(self, screen, scroll_x): Рисует текущий кадр с учётом прокрутки фона.

Использование:

Создаётся в Game для представления куриц и особых целей.
Обновляется и отрисовывается каждый кадр во время игры.

Особенности:

Поддержка анимированных GIF с покадровой отрисовкой.
Настраиваемые размер, скорость и пути к GIF через config.json.
Слоистая отрисовка (передний/средний план) для глубины.
Особое поведение для некоторых GIF (например, замена moorhuhn_001.gif на moorhuhn_002.gif).
Обработка ошибок при загрузке GIF.

5. Game (src/models/game/game.py)
Назначение: Координирует основную игровую логику, интегрируя все компоненты.
Основные методы:

__init__(self, screen, config): Инициализирует состояние игры, ресурсы и компоненты.
load_sound(self, sound_path): Загلاین звуковой файл с громкостью из конфигурации.
load_cursor(self, cursor_path, scale): Загружает изображение пользовательского курсора.
start_background_music(self): Запускает игровую музыку.
stop_background_music(self): Останавливает игровую музыку.
handle_event(self, event): Обрабатывает пользовательский ввод (мышь, клавиатура).
check_hit(self, mouse_pos): Проверяет попадание выстрела по цели, обновляя счёт.
reset_game(self): Сбрасывает состояние игры для новой сессии.
draw_help(self): Отображает экран справки.
draw(self): Рисует игру, включая фоны, цели, интерфейс и курсор.
update(self): Обновляет состояние игры (таймеры, спавн целей, анимации).
start(self): Запускает игровой цикл.

Использование:

Создаётся в main.py и запускается при выборе "start game".
Управляет всем игровым процессом.

Особенности:

Параллакс-прокрутка с двумя слоями фона.
Пользовательский курсор для прицеливания.
Звуковые эффекты для выстрелов, попаданий и перезарядки.
Настраиваемые настройки уровня (таймер, частота спавна, скорости).
Интеграция с системой рекордов.
Меню паузы с опциями продолжения, просмотра рекордов, справки или выхода.
Обработка ошибок при загрузке ресурсов и отрисовке.
Отдельная игровая музыка, отличная от музыки меню.

6. Menu (src/models/menu.py)
Назначение: Управляет интерфейсом главного меню и навигацией.
Основные методы:

__init__(self, screen, config): Инициализирует меню, фон и музыку.
load_background(self): Загружает изображение фона меню.
load_music(self): Загружает и воспроизводит музыку меню.
stop_music(self): Останавливает музыку меню.
draw(self): Отображает меню с прокручиваемым фоном и опциями.
handle_event(self, event): Обрабатывает ввод с клавиатуры и мыши для навигации.

Использование:

Создаётся в main.py для главного меню.
Используется в Game для меню паузы.

Особенности:

Прокручиваемый фон с управлением мышью.
Четыре опции: "start game", "records", "help", "exit".
Настраиваемые шрифты, размеры и фон через config.json.
Отдельная музыка меню, отличная от игровой.
Обработка ошибок при загрузке фона и музыки.


Ключевые особенности
1. Разная музыка

Музыка меню: menu.mp3 воспроизводится в главном и паузном меню, загружается в Menu.__init__ и останавливается в Menu.stop_music.
Игровая музыка: game.mp3 воспроизводится во время игры, управляется методами Game.start_background_music и Game.stop_background_music.
Реализация:
Музыка загружается с помощью pygame.mixer.music.load и воспроизводится с play(-1) для зацикливания.
Громкость задаётся через config.json (entities.sounds.volume).
Переходы (например, из меню в игру) останавливают текущую музыку перед запуском новой, чтобы избежать наложения.


Состояния:
Меню: Музыка играет в состоянии in_menu или при паузе (если не отображаются рекорды/справка).
Игра: Музыка играет во время активного игрового процесса.
Рекорды/Справка: Музыка не воспроизводится, чтобы акцентировать внимание на тексте.



2. Централизованная конфигурация

Файл: config.json хранит все настройки, доступные через ConfigLoader.
Преимущества:
Упрощает изменение параметров игры (например, размер экрана, таймеры уровней, размеры сущностей).
Единый источник данных для всех классов.
Расширяемость для добавления новых уровней или сущностей.


Использование:
Загружается в main.py и передаётся в Game, Menu, Gun, TableRecords.
GifObject использует конфигурацию для путей к GIF и размеров.
Пути к звукам и изображениям задаются относительно корня проекта.



3. Модульная структура классов

Разделение:
Каждый класс (ConfigLoader, TableRecords, Gun, GifObject, Game, Menu) находится в отдельном файле.
src/models/game/ группирует классы, специфичные для игры.
src/utils/ содержит утилиты, такие как ConfigLoader.


Преимущества:
Улучшенная поддерживаемость и читаемость.
Упрощение тестирования и расширения отдельных компонентов.
Чёткие пути импорта (например, from .gun import Gun в game.py).



4. Обработка ошибок

Загрузка файлов:
Изображения: Запасной вариант — цветная поверхность при ошибке (например, Gun.load_pistol_image, Game.load_cursor).
Звуки: Возврат None при ошибке (например, Game.load_sound).
JSON: Возврат пустого словаря при ошибке (например, ConfigLoader.load_config, TableRecords.load_scores).


Отрисовка:
Вызовы subsurface защищены проверками размеров, чтобы избежать сбоев (например, в Game.draw, Menu.draw).


Музыка:
Ошибки при загрузке/воспроизведении музыки логируются без прерывания работы (например, Menu.load_music, Game.start_background_music).



5. Параллакс-фон

Реализация:
Два слоя (b1.png, b3.png) с разными коэффициентами параллакса (0.7, 1.0), заданными в config.json.
Слои масштабируются до 2400x800 и прокручиваются на основе scroll_x в Game.draw.


Эффект:
Создаёт ощущение глубины за счёт разной скорости движения слоёв фона.
Управляется положением мыши (края экрана изменяют scroll_x).



6. Пользовательский курсор

Реализация:
Загружается из cursor.png, масштабируется до 32x32 (настраивается в config.json).
Отрисовывается по центру позиции мыши в Game.draw.
pygame.mouse.set_visible(False) скрывает стандартный курсор.


Сброс:
Видимость восстанавливается в main.py при завершении, чтобы не повлиять на систему.



7. Рекорды

Хранение:
Сохраняются в high_scores.json как словарь имён игроков и их очков.
Управляется методами TableRecords.save_score и TableRecords.load_scores.


Отображение:
Показываются 5 лучших рекордов в TableRecords.draw, доступны через меню или после окончания игры.
Игроки вводят своё имя после окончания игры (ограничение — 20 символов).




Инструкции по использованию
Требования

Python: Версия 3.6 или выше.
Зависимости:
pygame: Для рендеринга игры и работы со звуком.
Pillow: Для извлечения кадров из GIF.
Установка:pip install pygame Pillow





Настройка

Склонируйте или создайте директорию проекта со структурой, описанной выше.
Убедитесь, что все изображения и звуковые файлы находятся в директориях img/ и sound/.
Создайте пустой файл high_scores.json в корне проекта (например, {}), если он отсутствует.
Проверьте, что config.json корректно настроен с путями относительно корня проекта.

Запуск игры

Перейдите в директорию проекта:cd game


Запустите основной скрипт:python main.py


Игра начнётся с меню. Используйте клавиатуру (вверх/вниз, Enter) для навигации и выбора опций.

Управление

Меню:
Вверх/Вниз: Навигация по опциям меню.
Enter: Выбор опции.
Мышь: Движение влево/вправо для прокрутки фона.


Игра:
Движение мыши: Прицеливание; движение к краям экрана прокручивает фон.
Левый клик: Выстрел (если есть боеприпасы).
Стрелки влево/вправо: Перемещение первой цели (для отладки).
Esc: Пауза игры.


Конец игры:
Клавиатура: Ввод имени игрока, Backspace для удаления, Enter для сохранения.
Любая клавиша: Возврат в меню после просмотра рекордов.


Рекорды/Справка:
Любая клавиша: Возврат в меню.




Детали реализации
Управление музыкой

Меню:
Музыка загружается и воспроизводится в Menu.__init__ с помощью pygame.mixer.music.play(-1).
Останавливается в Menu.stop_music при переходе к игре, рекордам или справке.


Игра:
Музыка загружается и воспроизводится в Game.start_background_music.
Останавливается в Game.stop_background_music при паузе, окончании игры или переходе к другим состояниям.


Переходы:
Текущая музыка останавливается перед запуском новой для предотвращения наложения.
Громкость настраивается через config.json.



Конфигурация

Файл: config.json является единым источником настроек.
Доступ: ConfigLoader предоставляет интерфейс для загрузки и доступа к конфигурации.
Гибкость: Поддерживает добавление новых уровней, сущностей и параметров.

Обработка ошибок

Загрузка ресурсов:
Изображения и звуки имеют запасные варианты (поверхности, None).
JSON-файлы возвращают пустые структуры при ошибке.


Отрисовка:
Проверки размеров для subsurface предотвращают сбои.


Логирование: Ошибки записываются в консоль без прерывания работы.

Параллакс-фон

Слои: Два слоя фона (b1.png, b3.png) с коэффициентами 0.7 и 1.0.
Прокрутка: Управляется переменной scroll_x, изменяемой положением мыши.
Эффект: Разная скорость слоёв создаёт глубину.

Пользовательский курсор

Отрисовка: Центрируется на позиции мыши, скрывая стандартный курсор.
Сброс: Видимость курсора восстанавливается при выходе из игры.

Рекорды

Хранение: JSON-файл high_scores.json сохраняет пары имя-очки.
Ввод: После игры игрок вводит имя, которое сохраняется при нажатии Enter.
Отображение: Таблица рекордов показывает 5 лучших результатов.


Заключение
Игра Moorhuhn реализована с акцентом на модульность, надёжность и гибкость конфигурации. Централизованный файл config.json упрощает настройку, а разделение классов по файлам улучшает читаемость и поддерживаемость. Отдельная музыка для меню и игры, параллакс-фон и пользовательский курсор создают увлекательный игровой процесс. Надёжная обработка ошибок гарантирует стабильность даже при отсутствии ресурсов.
