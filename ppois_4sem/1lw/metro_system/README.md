# Metro System

Упрощенная модель метро с интерфейсом командной строки (CLI), разработанная на Python. Проект моделирует работу метро, включая станции, поезда, расписание, пассажиров, билеты и турникеты.

## Описание

Система позволяет пользователям:
- Создавать станции метро и управлять их состоянием.
- Создавать пассажиров, которые могут покупать билеты, проходить через турникеты и садиться в поезда.
- Управлять расписанием поездов и их движением.
- Сохранять и загружать состояние системы между запусками.

Проект разработан с учетом стандарта PEP 8, аннотаций типов и юнит-тестов. Включает UML-диаграммы для визуализации структуры и поведения.

## Доступные команды
После запуска вы увидите приглашение для ввода команд. Поддерживаются следующие команды:
- add_station — Добавить новую станцию (например, "Central").
- create_passenger — Создать пассажира с указанием имени и начальной суммой денег.
- go_to_station — Отправить пассажира на станцию.
- buy_ticket — Купить билет для пассажира.
- pass_turnstile — Пройти через турникет с билетом.
- board_train — Проверить расписание и сесть в поезд.
- save — Сохранить текущее состояние системы в файл metro_state.json.
- load — Загрузить состояние системы из файла metro_state.json.
- list_stations — Показать список всех станций (рекомендуется добавить).
- exit — Завершить работу программы.
- help — Показать список команд

### Пример использования:
Введите команду (help для списка): add_station
Введите имя станции: Central
Станция Central добавлена.
Введите команду (help для списка): create_passenger
Введите имя пассажира: Alice
Пассажир Alice создан.
Введите команду (help для списка): go_to_station
Введите имя станции: Central
Alice входит на станцию Central.
